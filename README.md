# ملف إنجاز المعلم

موقع ثابت (HTML وCSS وJavaScript فقط) يساعد المعلم/ـة على تنظيم شواهد **عناصر الأداء الوظيفي الأحد عشر** حسب نظام إدارة الأداء الوظيفي، ومتابعة نسبة الإنجاز الموزونة، وتوليد تقارير رسمية جاهزة للطباعة، ومشاركة الملف مع المقيّم برابط واحد أو رمز QR.

> الموقع أداة شخصية وغير تابع رسمياً لوزارة التعليم.

## المزايا

- **لوحة الإنجاز** (`index.html`): بطاقة المعلم، وعدّاد دائري للإنجاز الموزون (الوزن × نسبة الشواهد المكتملة في كل عنصر)، وبطاقات العناصر الـ 11 مع شارة ذهبية عند اكتمال العنصر 100%.
- **صفحة العنصر** (`element.html?id=N`): الملخص، وأمثلة التحقق، وقائمة تحقق الشواهد مع حقل لرابط كل شاهد، وزر لفتح مجلد العنصر في Drive، وأفكار إبداعية، وتقارير جاهزة، ورمز QR لعرض المقيّم.
- **مولّد التقارير** (`report.html?id=rX-Y`): نموذج معبأ مسبقاً، ومعاينة حية بتنسيق A4 رسمي، وطباعة أو حفظ PDF، ونسخ النص.
- **عرض المقيّم** (`evaluator.html`): صفحة للقراءة فقط تُبنى من الرابط نفسه، ويمكن طباعتها كملخص.
- **الإعدادات** (`settings.html`): بيانات المعلم، وتصدير نسخة احتياطية JSON واستيرادها، ومسح البيانات.

جميع البيانات تُحفظ في متصفحك (localStorage) فقط، ولا يوجد خادم.

## تفعيل GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع على GitHub (مثلاً باسم `ada1448`).
2. افتح المستودع ثم **Settings ← Pages**.
3. في **Build and deployment** اختر **Source: Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. بعد دقيقة أو دقيقتين يصبح الموقع متاحاً على:
   `https://<اسم-المستخدم>.github.io/ada1448/`

ملف `.nojekyll` موجود ليُنشر الموقع كما هو دون معالجة Jekyll. جميع المسارات نسبية، فيعمل الموقع تحت أي مسار فرعي.

## كيف أضيف شواهدي؟

1. افتح **الإعدادات** وأدخل اسمك وتخصصك ومدرستك وإدارة التعليم والعام الدراسي واسم المدير/ة، لتظهر تلقائياً في التقارير.
2. من لوحة الإنجاز افتح أي عنصر.
3. اضغط **«ارفع شواهدك في Drive»** لفتح مجلد العنصر، وارفع ملفاتك.
4. في Drive انقر على الملف بزر الفأرة الأيمن واختر **مشاركة ← نسخ الرابط**، واحرص على أن تكون المشاركة «أي شخص لديه الرابط» حتى يستطيع المقيّم فتحه.
5. ارجع إلى صفحة العنصر، وضع علامة ✓ أمام الشاهد، والصق الرابط في حقله. تُقبل الروابط التي تبدأ بـ `http://` أو `https://` فقط.
6. تتحدث نسبة الإنجاز تلقائياً.

## مشاركة الملف مع المقيّم

- من الرئيسية اضغط **«إنشاء رابط المقيّم»**، فيُنسخ الرابط ويظهر رمز QR له.
- يحمل الرابط بياناتك وشواهدك المنجزة **وقت إنشائه**. لذلك أنشئ رابطاً جديداً بعد إضافة شواهد.
- في صفحة كل عنصر يوجد رمز QR يفتح عرض المقيّم على ذلك العنصر مباشرة.

## النسخ الاحتياطي

بياناتك موجودة في هذا المتصفح فقط، وقد تضيع إذا مُسحت بيانات المتصفح. من **الإعدادات** صدّر ملف JSON بانتظام واحفظه في Drive، ويمكنك استيراده على أي جهاز آخر.

## هيكل الملفات

```
index.html  element.html  report.html  evaluator.html  settings.html
assets/css/style.css
assets/js/store.js      التخزين والحساب الموزون وترميز رابط المقيّم
assets/js/app.js        الترويسة والتذييل وشريط الجوال وأدوات مشتركة
assets/js/<page>.js     منطق كل صفحة
data/elements.js        بيانات العناصر والشواهد (window.ELEMENTS)
data/reports.js         قوالب التقارير (window.REPORTS)
```

لتعديل المحتوى عدّل `data/elements.js` و`data/reports.js` فقط، مع الالتزام بالمخطط نفسه.
